    structure Signals.Contracts.ResidualContract (Measurement : Type u_1) (Prediction : Type u_2) (Residual : Type u_3) :
    Type (max (max u_1 u_2) u_3)

    A measured-versus-predicted result with an explicit residual law.

    The residual and magnitude functions are parameters of the contract rather than global subtraction or norm operations. This keeps units and domain semantics in the specialized adapter while allowing common acceptance tooling.

    • measured : Measurement
    • predicted : Prediction
    • residual : Residual
    • residualFunction : Measurement → Prediction → Residual
    • residualLaw : self.residual = self.residualFunction self.measured self.predicted
    • magnitude : Residual → ℝ
    • magnitude_nonnegative : 0 ≤ self.magnitude self.residual
    • tolerance : ℝ
    • tolerance_nonnegative : 0 ≤ self.tolerance
    • withinTolerance : self.magnitude self.residual ≤ self.tolerance

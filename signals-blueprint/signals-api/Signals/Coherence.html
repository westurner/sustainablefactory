          structure Signals.Coherence.CoherenceSpectrum (dimension : ℕ) :
          Type

          A normalized finite spectrum for the polarization coherence matrix.

          The entries represent the normalized eigenvalues m_i used in the paper's arbitrary-dimensional construction. The spectrum is finite data; it does not assert that a particular optical source or quantum state realizes it.

          • weight : Fin dimension → ℝ
          • weight_nonnegative (index : Fin dimension) : 0 ≤ self.weight index
          • normalized : ∑ index : Fin dimension, self.weight index = 1

                  structure Signals.Coherence.HuygensSteinerMapping :
                  Type

                  A barycentric inertia mapping for the normalized spectrum model.

                  The origin-axis inertia and center-axis inertia are related by the Huygens-Steiner theorem. The two squared optical quantities are recorded as the corresponding normalized inertia difference and its complement.

                  • axis : ParallelAxis
                  • originInertia : ℝ
                  • originInertiaLaw : self.originInertia = self.axis.inertia
                  • normalizedMass : self.axis.mass = 1
                  • polarizationSquared : ℝ
                  • entanglementSquared : ℝ
                  • polarizationSquared_nonnegative : 0 ≤ self.polarizationSquared
                  • entanglementSquared_nonnegative : 0 ≤ self.entanglementSquared
                  • polarizationLaw : self.polarizationSquared = self.originInertia - self.axis.centerInertia
                  • entanglementLaw : self.entanglementSquared = 1 - (self.originInertia - self.axis.centerInertia)

                    theorem Signals.Coherence.CoherenceSpectrum.binary_polarization_and_entanglement (spectrum : CoherenceSpectrum 2) :
                    spectrum.polarizationSquared = (spectrum.weight 0 - spectrum.weight 1) ^ 2 ∧ spectrum.entanglementSquared = 4 * spectrum.weight 0 * spectrum.weight 1

                    For a binary ($N = 2$) coherence spectrum (CoherenceSpectrum 2, e.g. two slits with normalized weights $m_0 + m_1 = 1$ in Qian & Izadi, Phys. Rev. Research 5, 033110 (2023)), the squared degree of polarization equals the squared weight imbalance $(m_0 - m_1)^2$ and the squared Schmidt entanglement/visibility equals $4 m_0 m_1$.

    Layer-code construction data #

    Williamson and Baspin, Layer codes (Nature Communications 15, 9528, 2024), describe a construction that transforms CSS stabilizer codes into three- dimensional topological codes built from surface-code layers and one- dimensional junctions. The records here preserve finite code parameters and reported scaling assumptions; they do not implement a decoder or prove a hardware threshold. See Signals.QECReferences for the reference-only registry linking the Error Correction Zoo entries and the external QECLean formalization candidate.

      Finite metadata about an output of the Layer-code lift.

      The construction metadata makes its geometric and stabilizer constraints explicit. optimalScalingClaimed is a status flag supplied by the model and is not a theorem about every input code. This is not a Pauli, homology, or decoder implementation.

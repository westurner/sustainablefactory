    WS-3: Exact Affine Layer-Group Operations Modulo 2D Lattice Translations #

    Layer groups are 3D subperiodic crystallographic symmetry groups that are periodic in two lattice directions (u, v) and finite/non-periodic in the out-of-plane coordinate z. Every operation in all 80 International Tables Vol. E layer groups can be written in the appropriate Bravais basis (oblique, rectangular, square, or hexagonal) as an exact integer 3 × 3 point-group matrix R with R_{2,0} = R_{2,1} = 0, R_{0,2} = R_{1,2} = 0, R_{2,2} ∈ {-1, 1}, and a half-integer in-plane translation (t_u / 2, t_v / 2, 0) modulo ℤ² × {0} (so t_u, t_v ∈ Fin 2).

    This module formalizes that exact quotient monoid/group action and proves check figures for representative layer groups without conflating crystallographic symmetry orders with electronic transport or QAHE claims.

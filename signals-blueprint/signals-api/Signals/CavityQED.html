    Cavity electrodynamics and Grover cavity-QED models #

    These finite records extract equations from Kipp et al., Cavity Electrodynamics of van der Waals Heterostructures (2024/2025), and Nagib, Saffman, and Mølmer, Efficient preparation of entangled states in cavity QED with Grover's algorithm and Deterministic carving of quantum states with Grover's algorithm (2025). They are conditional data contracts: Lean checks the supplied algebra, but does not assert that an arbitrary cavity realizes the model or that a target fidelity is experimentally achieved.

    structure Signals.Pending.CoupledCavityModes :
    Type

    A pair of coupled cavity and matter modes with hybridized frequencies.

    The two hybrid frequencies are the eigenvalues of the real symmetric normalized two-mode coupling matrix. Frequencies are stored in hertz and the coupling is stored in the same frequency convention.

    • cavityFrequency : Units.Frequency
    • cavityFrequency_pos : 0 < self.cavityFrequency.hz
    • matterFrequency : Units.Frequency
    • matterFrequency_pos : 0 < self.matterFrequency.hz
    • couplingFrequency : Units.Frequency
    • couplingFrequency_nonnegative : 0 ≤ self.couplingFrequency.hz
    • lowerHybridFrequency : Units.Frequency
    • lowerHybridFrequency_nonnegative : 0 ≤ self.lowerHybridFrequency.hz
    • upperHybridFrequency : Units.Frequency
    • upperHybridFrequency_pos : 0 < self.upperHybridFrequency.hz
    • modeSplitting : Units.Frequency
    • modeSplitting_nonnegative : 0 ≤ self.modeSplitting.hz
    • normalizedCoupling : ℝ
    • lowerHybridLaw : self.lowerHybridFrequency.hz = (self.cavityFrequency.hz + self.matterFrequency.hz) / 2 - √(((self.cavityFrequency.hz - self.matterFrequency.hz) / 2) ^ 2 + self.couplingFrequency.hz ^ 2)
    • upperHybridLaw : self.upperHybridFrequency.hz = (self.cavityFrequency.hz + self.matterFrequency.hz) / 2 + √(((self.cavityFrequency.hz - self.matterFrequency.hz) / 2) ^ 2 + self.couplingFrequency.hz ^ 2)
    • modeSplittingLaw : self.modeSplitting.hz = self.upperHybridFrequency.hz - self.lowerHybridFrequency.hz
    • normalizedCouplingLaw : self.normalizedCoupling = self.couplingFrequency.hz / self.cavityFrequency.hz

    abbrev Signals.Maxwell.Vector3 :
    Type

    A three-component real spatial vector.

    Vector fields are represented directly, without Euler angles or orientation charts. This is the representation-level reason the model has no gimbal-lock state.

      structure Signals.Maxwell.VectorCalculus :
      Type

      Abstract vector-calculus operators used by the pointwise Maxwell model.

      The two identities record the differential facts needed below. A concrete calculus implementation must provide them; they are not global axioms.

      • divergence : Vector3 → ℝ
      • curl : Vector3 → Vector3
      • vectorTimeDerivative : Vector3 → Vector3
      • scalarTimeDerivative : ℝ → ℝ
      • divergence_curl (vector : Vector3) : self.divergence (self.curl vector) = 0
      • divergence_add (left right : Vector3) : self.divergence (left + right) = self.divergence left + self.divergence right
      • divergence_timeDerivative (vector : Vector3) : self.divergence (self.vectorTimeDerivative vector) = self.scalarTimeDerivative (self.divergence vector)

            structure Signals.Maxwell.System (calculus : VectorCalculus) :
            Type

            Macroscopic Maxwell fields and sources in three-vector notation.

            The fields use the standard $(E,D,B,H)$ convention and the source terms are charge density rho and current density current.

            • electricField : Vector3
            • displacementField : Vector3
            • magneticField : Vector3
            • magneticIntensity : Vector3
            • rho : ℝ
            • current : Vector3
            • gaussElectric : calculus.divergence self.displacementField = self.rho
            • gaussMagnetic : calculus.divergence self.magneticField = 0
            • faraday : calculus.curl self.electricField = -calculus.vectorTimeDerivative self.magneticField
            • ampere : calculus.curl self.magneticIntensity = self.current + calculus.vectorTimeDerivative self.displacementField

                  structure Signals.Maxwell.OriginalVacuumSystem (calculus : VectorCalculus) :
                  Type

                  Maxwell's equations after imposing isotropic vacuum constitutive laws.

                  This is the compact pre-tensor vector-calculus form often used for Maxwell's original field equations: no metric tensor, coordinate frame, or Euler-angle orientation is part of the representation.

                  • parameters : MaterialParameters
                  • electricField : Vector3
                  • magneticField : Vector3
                  • rho : ℝ
                  • current : Vector3
                  • gaussElectric : calculus.divergence self.electricField = self.rho / self.parameters.permittivity
                  • gaussMagnetic : calculus.divergence self.magneticField = 0
                  • faraday : calculus.curl self.electricField = -calculus.vectorTimeDerivative self.magneticField
                  • ampere : calculus.curl self.magneticField = self.parameters.permeability • self.current + (self.parameters.permeability * self.parameters.permittivity) • calculus.vectorTimeDerivative self.electricField

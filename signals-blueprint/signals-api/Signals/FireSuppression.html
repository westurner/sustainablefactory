    def Signals.netChainArrestHeatSavings (N_chain deltaH_cycle deltaH_rec : ℝ) :
    ℝ

    Net avoided combustion heat per terminated radical pair $\Delta Q_{\mathrm{avoided}}(N_{\mathrm{chain}}, \Delta H_{\mathrm{cycle}}, \Delta H_{\mathrm{rec}}) = N_{\mathrm{chain}}\,\Delta H_{\mathrm{cycle}} - \Delta H_{\mathrm{rec}}$: terminating a radical pair via $\cdot\mathrm{OH} + \mathrm{H}\cdot + M \to \mathrm{H}_2\mathrm{O} + M$ immediately releases $\Delta H_{\mathrm{rec}} \approx 499\text{ kJ/mol}$ of exothermic bond enthalpy, so it reduces cumulative heat release if and only if the prevented chain-propagation multiplier $N_{\mathrm{chain}}$ satisfies $N_{\mathrm{chain}}\,\Delta H_{\mathrm{cycle}} > \Delta H_{\mathrm{rec}}$.

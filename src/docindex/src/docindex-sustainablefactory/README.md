# docindex-sustainablefactory

Sustainablefactory-specific implementation package for the reusable docindex components.

This package is one implementation of:

- docindex-core
- docindex-sphinx
- docindex-cli

It keeps project-specific wiring, defaults, and migration compatibility for existing sustainablefactory integrations.

## Install

```bash
pip install docindex-sustainablefactory
```

## Components

- Generic primitives: `docindex_core`
- Sphinx extension: `docindex_sphinx`
- CLI command set: `docindex_cli`
- Project implementation shim: `docindex_sustainablefactory`
